# QuizDesk 5.17.0 — measured source optimization — 28/10/2026

Changes:
- Replace library snapshot JSON roundtrip with direct deep copying. Every model field,
  mutable list/dictionary/set and media byte array retains independent ownership.
- Concurrent metadata-only library summary cache, invalidated on successful writes,
  file length/write/creation-time changes, deletions and missing folders. Actual Load
  still parses/validates the file. No persisted schema change or full-bank cache.
- Random.Shuffle over list spans replaces random-key sorting; skip empty media scans.
  Correct-answer and attached-media mapping remain tested; fixed seeds reproducible.
- First-frame decode moves entirely to bounded background workers. Normal budget is
  clamp(Environment.ProcessorCount - 1, 1, 4); Performance Mode admits one lean job
  at a time. Existing jobs finish normally. Stale detached loads skip decode/release results.
- Copy premultiplied BGRA from live Skia bitmap to locked framebuffer using bounded
  spans, checked lengths, stride validation and row-padding handling. No per-frame row
  array; GIF frame metadata cached. Unsafe code is confined to this internal copy helper.
- Save newly imported banks on a background task while the import UI stays disabled.
- No validation/media limit reduction, quality reduction, forced software/GPU backend,
  GC forcing, OS power-plan change or deferred/coalesced answer checkpoint writes.

Measured on the development Windows host (not a low-spec hardware guarantee):

| Copy 100 × 1024×768 BGRA frames, same process | 20.2785 ms | 8.0777 ms |

Catalog rows compare a full verified read to a subsequent cached read, not application
startup or a disk-independent universal speedup. Copy numbers measure only copying,
not total GIF decoding/upload/render frame time.

summary-cache optimization, which does not participate in the active-exam hot path.
