# macOS installation fallback — 26/10/2026

User reports QuizDesk-Setup-5.14.0-macos-arm64.pkg fails on macOS 26,
with only a generic contact-the-developer message. No installation log is available.
The PKG root cause remains unconfirmed; this change does not claim to fix that package.

macOS release assets switch to a verified DMG for each architecture. PKG remains
an Actions diagnostic artifact. Its real ARM64 install probe is allowed to fail
with an explicit step summary and logs; it cannot authorize PKG publication.
DMG build/verification errors remain fatal. Existing published assets/tags are unchanged.

Checks run on Windows:
- 11 packaging tests passed, including ARM64/Intel DMG mount/copy orchestration,
  signature-failure cleanup/no checksum, wrong architecture and overwrite rejection.
  Apple commands and Unix symlinks are mocked in these portable tests.
- 28 release publication tests passed, with GitHub calls mocked and no network writes.
  Includes separate DMG checksums and rejection of tampered DMG before any API call.
- actionlint passed for all four workflows; git diff --check passed.

The real macOS build must still run on Actions: hdiutil create/verify/attach, mounted
and copied app signature/version/architecture verification, and detach. No real DMG
was generated on this Windows host; no native UI launch was performed. Ad-hoc signing
is not Developer ID signing or notarization and cannot remove Gatekeeper warnings.

Because v5.14.0 is already published, a new commit with that same version retains
its DMG in Actions Artifacts. A new synchronized version is needed for a new Release;
this work does not move the existing tag, replace assets or push source.
