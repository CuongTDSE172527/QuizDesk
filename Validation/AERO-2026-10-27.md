# Windows Aero glass — 27/10/2026

Implementation:
- Desktop Windows only. Request AcrylicBlur, then Blur, then None.
- Set a theme-appropriate opaque TransparencyBackgroundFallback; only install
  translucent resource palette when ActualTransparencyLevel reports blur.
- Keep text and semantic feedback colors opaque. Cards use a high-alpha tint;
  navigation/root expose more backdrop. Header uses a subtle static shine.
- One native blur layer per window, no per-card blur loops/timers or animations.
- Persist AeroGlass preference, default true; older settings keep the default.
- Detach property handler/resources on view removal, reattach on return.
- No native P/Invoke, new package dependency, version bump, commit or push.
