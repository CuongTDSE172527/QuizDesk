# QuizDesk 5.16.7 — glass tuning — 27/10/2026

Settings: GlassBrightness integer [-50,50], default 0; GlassTransparency [0,100],
default 50. Existing AeroGlass setting and schema version remain compatible.
Brightness blends base RGB toward white/black up to 18%, independently of alpha.
Transparency is relative effect strength: 0 is opaque, 50 preserves previous alpha,
100 reaches role-specific floors. Text/semantic colors and their opacity are unchanged.
Portable backdrop stops remain opaque. No actual wallpaper/native blur on mobile added.

Rendering: cache original tint colors and update mutable brushes/stops in place,
without reconstructing pages or requesting native blur per slider movement. This
prevents accumulated tint errors and unnecessary layout/window changes.

Persistence: one 250 ms DispatcherTimer groups saves during drag; flush pending
values on PersistSession (pause/deactivation) and detach. Remove timer handler on
detach. Slider controls disabled while glass is off and accessible names provided.
